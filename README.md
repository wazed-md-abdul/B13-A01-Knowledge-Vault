**Knowledge Vault** is a centralized hub designed to store, categorize, and showcase technical documentation and web development resources. It’s built to be a "single source of truth" for my learning journey.

## 🗝️ Core Features
- **Categorized Sections:** Effortlessly browse through different topics (HTML, CSS, JS).
- **Responsive Archive:** Fully optimized for mobile reading and desktop research.
- **Modern UI/UX:** A clean, minimal interface that puts the content first.
- **Quick Search:** Designed for rapid access to key information.

## 🛠️ Technology Stack
- **HTML5:** Semantic structure for SEO and accessibility.
- **Tailwind CSS:** For a sleek, modern, and high-performance design.
- **Lucide Icons:** (Optional - change if you used different icons) for clean visual cues.
